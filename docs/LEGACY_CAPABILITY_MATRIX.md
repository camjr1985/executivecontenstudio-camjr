# Legacy Capability Matrix

Ground truth for every row below is `legacy-netlify-snapshot/{index.html,app.js,data.js,covers.js,styles.css}` (1,481 lines of app logic, read in full) plus a live check against `executivecontenstudio.netlify.app`. Nothing here is inferred from a prior audit's summary — the 2026-09-02 audit only inspected the calendar data model, not the full app, which is why it undercounted the legacy feature set.

Sidebar order in the legacy app: Hoje, Posts, Carrosséis, Artigos, Notícias, Comentários, Sugestões de Comentário, Calendário, Revisões Mensais, Banco de Ideias, Categorias, Pesquisa, Guia de Escrita, Gerir Conteúdo.

**Summary:** 14 of 16 legacy capabilities restore directly (Posts/Carousels/Articles copy only for the 41 EXISTING records — genuinely no copy exists yet for the 38 NEW ones). News restores as an honestly-empty reserve workspace (legacy itself never had real news content either). The local-CRUD/import capability and the fake publish toggle are the two the brief's own constraints (`WRITE_MODE=CONTROLLED`, no writeback) argue against restoring as-built — both get scaled back rather than ported verbatim, with the reasoning above.
